# ESP8266 智能灭蚊计数器

> 用 ESP8266 + ACS712 电流检测模块改装 USB 5V 电击灭蚊灯，自动统计灭蚊数量并在网页/手机查看实时数据与每小时柱状图。

## 二、原理说明

电击灭蚊灯内部是一个 5V→数千伏的升压电路，正常工作时升压电路有较稳定的低电流。
当蚊子触碰高压网时，**高压网瞬间放电短路**，会导致 5V 输入端出现一个**陡峭的电流尖峰**（持续几毫秒）。

```
没蚊子时：    USB线电流 ≈ 平稳的 100~300mA
有蚊子击杀： USB线电流 → 瞬间冲到 500mA~1A → 立刻回落
```

ACS712 串联在 USB 红线（+5V）上，通过霍尔效应把电流转成电压输出到 ESP8266 的 ADC 引脚（A0），程序识别尖峰即认为击杀一只。

## 三、接线图

### 3.1 ACS712 改造 USB 线

```
        [USB 公头]                                        [USB 母头]
         接电源                                          接灭蚊灯
            │                                               │
   红 +5V ──┴──→ ACS712 [IP+] ═══电流通路═══ [IP-] ──→ 红 +5V
   黑 GND ─────────────────直通────────────────────────→ 黑 GND
   D+/D- ──────────────────直通（不动）─────────────────→ D+/D-
```

把一根 USB 线**只剪断红色（+5V）那一根**，两端分别接到 ACS712 模块上的 `IP+` 和 `IP-` 螺丝端子。黑线 GND 保持完整不动。

### 3.2 ACS712 信号端 → NodeMCU

⚠️ **重要分压**：ACS712 用 5V 供电时，OUT 静态电压是 2.5V，尖峰可能到 4V+，超过 NodeMCU A0 安全范围。
解决方案：**用 3.3V 给 ACS712 供电**（最简单，本方案采用），或加 10kΩ + 10kΩ 分压电阻。

> 用 3.3V 供电时灵敏度会下降，但对识别"尖峰"足够。如果实测灵敏度不够，再改回 5V 供电 + 分压电阻。

```
ACS712 模块         NodeMCU
─────────────       ─────────
   VCC      ───→    3V3
   GND      ───→    GND
   OUT      ───→    A0
   IP+,IP-          串入 USB 红线（见 3.1）
```

### 3.3 OLED（可选）

```
SSD1306 OLED        NodeMCU
─────────────       ─────────
   VCC      ───→    3V3
   GND      ───→    GND
   SCL      ───→    D1  (GPIO5)
   SDA      ───→    D2  (GPIO4)
```

### 3.4 蜂鸣器（可选）

```
有源蜂鸣器          NodeMCU
─────────────       ─────────
   +(VCC)   ───→    D5  (GPIO14)
   -(GND)   ───→    GND
```

### 3.5 复位按钮（可选）

```
按钮一端  ───→  D6 (GPIO12)
按钮另一端 ──→  GND
```
（代码里 D6 启用内部上拉，按下=低电平=清零计数；长按 3 秒进入阈值校准）

### 3.6 完整接线总表

| NodeMCU 引脚 | 接到 | 用途 |
|---|---|---|
| `3V3` | ACS712 VCC, OLED VCC | 3.3V 供电 |
| `GND` | ACS712 GND, OLED GND, 蜂鸣器- , 按钮 | 公共地 |
| `A0` | ACS712 OUT | 电流模拟读数 |
| `D1 (GPIO5)` | OLED SCL | I2C 时钟 |
| `D2 (GPIO4)` | OLED SDA | I2C 数据 |
| `D5 (GPIO14)` | 蜂鸣器 + | 击杀提示音 |
| `D6 (GPIO12)` | 按钮 | 复位/校准 |
| `Vin` | 不接 | （NodeMCU 由 USB 口单独供电） |

## 四、供电方案

最简洁：**两个 USB 接口分别供电**
- 灭蚊灯 USB 接 5V/1A 充电头（经 ACS712 串入）
- NodeMCU USB 接电脑或另一个充电头

也可以共用一个电源，但要注意 ACS712 串在灭蚊灯供电线上时，NodeMCU 的电要从 ACS712 **之前**取（否则 NodeMCU 自己的电流也被算进去）。

## 五、阈值校准流程

1. 烧录代码后，串口监视器（115200 波特率）打开 Arduino IDE 的"串口绘图器"。
2. 灭蚊灯通电、ESP8266 通电，等 30 秒看基线波形稳定。
3. 用**绝缘镊子**短接一下高压网（或等真蚊子飞进去），观察 A0 读数的尖峰幅度。
4. 把代码里的 `KILL_THRESHOLD` 设成 "尖峰幅度 × 0.6"。
5. 也可以打开网页 `http://<ESP8266 IP>/`，里面有"实时电流幅度"显示和阈值滑块，**网页上直接调阈值无需重烧**。

## 六、固件功能

- WiFi 配网：首次启动开启 AP 模式（SSID: `MosquitoKiller-Setup`），手机连入后自动跳出配网页面，输入家里 WiFi 即可（基于 WiFiManager 库）。
- 内置网页：访问 ESP8266 的局域网 IP（OLED 上会显示），即可看到：
  - 总击杀数
  - 今日击杀数
  - 最近 24 小时柱状图
  - 实时电流尖峰幅度
  - 阈值调节滑块
  - 一键清零按钮
- 数据持久化：击杀总数和每小时计数保存在 ESP8266 的 LittleFS（断电不丢失）。
- 防抖：两次计数最小间隔 300ms，避免一只蚊子被算多次。

## 九、安全注意

1. **绝对不要带电触碰灭蚊灯的高压网**，断电后高压电容仍可能存电，先放电再操作。
2. ACS712 串接 USB 红线时焊接处必须**热缩管/绝缘胶带绝缘**，5V 短路会烧坏电源。
3. ESP8266 的 A0 最大 3.3V，本方案用 3.3V 供电 ACS712 已规避，**不要用 5V 供电而省略分压**。
4. 灭蚊灯放置位置**远离儿童和宠物**。
5. 改装后建议先用万用表检查 USB 线 +5V 和 GND 是否正确再通电。
